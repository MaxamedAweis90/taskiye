# Taskiye - V2 Backlog & Future Roadmap

The following features are intentionally deferred to post-MVP releases to preserve scope discipline and ensure rapid initial deployment.

## 1. Appearance & Theme Enhancements

- Native Dark Mode toggle and auto-system theme switching.
- Customizable visual theme palettes for dashboard accent colors.

## 2. Notifications & Reminders

- Push notifications for daily task reminders.
- Email digest summaries for weekly goal progress.

## 3. Advanced Analytics & Social Features

- Comprehensive habit streak tracking and historical stats breakdown.
- Export data functionality (CSV / JSON format).
- Team workspace and goal sharing capabilities.
