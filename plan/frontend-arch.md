# Taskiye - Frontend Architecture & State Strategy

## Core Tech Stack

- **Framework:** React + Vite + TypeScript
- **Routing:** React Router v6+
- **Local & Auth State:** Zustand (Local persistence, guest task limit, auth modal)
- **Server State & API Synchronization:** TanStack Query v5 (Data fetching, caching, optimistic updates)
- **Auth Client:** Better Auth Client
- **Styling & Assets:** Tailwind CSS (Slate color palette), Lucide Icons
